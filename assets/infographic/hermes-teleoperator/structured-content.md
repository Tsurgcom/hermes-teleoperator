# Hermes Teleoperator
## Objectives
Understand one conversation with remote native tools.
## Gateway
The model and conversation stay on the original computer.
## Destinations
Terminal, files and skills execute through the destination's own Hermes installation.
Remote MCP tools are discovered and called there, using its credentials.
## Transport
Strict SSH host-key checks, noninteractive key authentication, no agent forwarding, no listener beyond SSH.
